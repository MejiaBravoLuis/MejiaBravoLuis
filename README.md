## 💼 Experiencia profesional

### Iobot — Desarrollador Full-Stack
> Plataforma SaaS de chatbots multicanal y CRM para empresas

Desarrollo y mantenimiento de una API con **80+ rutas**, **170+ tablas** en base de datos y múltiples integraciones de terceros. Principales contribuciones:

- 🤖 **Motor de chatbots multicanal** — WhatsApp (Gupshup, Meta Cloud API, Woztell), Messenger, Instagram, Telegram y TikTok
- 🧠 **Integraciones de IA** — Análisis automático de chats con OpenAI, evaluación de agentes, extracción de cotizaciones, base de conocimiento con IA
- 🛒 **E-commerce & Delivery** — Catálogos de productos, flujo de órdenes, integración con Shopify, WooCommerce, ShipDay y sistemas de entrega propios
- 📊 **Reportería automatizada** — Reportes diarios para supervisores, reportes semanales en PDF, KPIs, video recaps con Remotion Lambda
- 🔄 **Workflows & Automatización** — Motor de workflows configurables, sistema de triggers con condiciones y acciones, campañas masivas programadas
- 💳 **Facturación & Pagos** — Procesamiento con Stripe, schemas de billing, planes de suscripción
- 🔐 **RBAC** — Sistema de roles, permisos y validación por middleware
- 📡 **Infraestructura** — Deploy en Fly.io (workers separados para API, IA y cron), Redis/Upstash para caché, AWS S3/SQS + Cloudflare R2, replicación read/write en PlanetScale, monitoreo con Prometheus
